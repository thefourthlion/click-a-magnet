# LibreTorrent — no Docker test stack

LibreTorrent is an **Android-only** torrent client. It cannot be run in Docker for desktop extension testing.

## Extension status

**Not supported** — mobile-only; no Web UI or RPC API for this extension to call.

## How to test manually

Use LibreTorrent on an Android device. Click a Magnet targets desktop/lan Web UIs from the browser on desktop.
