# Tixati — no Docker test stack

Tixati is a **Windows-focused desktop client**. There is no official Linux/Docker image or documented remote Web API for third-party browser extensions.

## Extension status

**Not supported** — no public Web UI API for integration.

## How to test manually

Run Tixati on Windows and use its built-in magnet handling. Not a target for Click a Magnet unless Tixati exposes a stable remote API in the future.
